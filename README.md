This is a solution to the [QR Code Component Challenge](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) on Frontend Mentor. The goal of this challenge is to build a simple and responsive QR code card component using HTML and CSS, and make it match the design as closely as possible.
